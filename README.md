
# Portfólio Pessoal — José Arnaldo

## Descrição

Projeto acadêmico de apresentação pessoal desenvolvido utilizando HTML5 e CSS3.

O objetivo é apresentar informações pessoais, formação acadêmica, experiências profissionais, competências e interesses relacionados à tecnologia.

## Páginas do projeto

- index.html: Página inicial e apresentação pessoal.
- curriculo.html: Currículo profissional.
- blog.html: Artigo sobre desenvolvimento Front-end.
- fotos.html: Galeria de imagens.
- contato.html: Formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Organização

O projeto possui cinco páginas HTML, um arquivo CSS compartilhado e um arquivo README.

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo index.html.
3. Execute utilizando a extensão Live Server ou diretamente pelo navegador.
